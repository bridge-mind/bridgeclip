# Transcription

BridgeClip has two per-run clipping modes. **Quality** (the default, including older requests) uses `anthropic/claude-opus-5.5` for planning and `microsoft/mai-transcribe-2` for transcription. **Economy** uses `z-ai/glm-5.3-flash` and `openai/whisper-large-v3-turbo`, with paid layout vision disabled and no higher-cost planner fallback. Automation metadata still uses MAI Transcribe 2. One OpenRouter key covers both modes.

The engine posts base64 audio JSON to `https://openrouter.ai/api/v1/audio/transcriptions` and requires `verbose_json` with word timestamps for either model. Quality requests Azure speaker diarization and passes custom vocabulary through `provider.options.azure.phraseList.phrases`. Economy does not request diarization; it passes vocabulary as a Groq prompt hint when Groq serves the request. See the [OpenRouter speech-to-text contract](https://openrouter.ai/docs/guides/overview/multimodal/stt), [MAI Transcribe 2](https://openrouter.ai/microsoft/mai-transcribe-2), and [Whisper Large V3 Turbo](https://openrouter.ai/openai/whisper-large-v3-turbo).

Audio stays at its original speed. Long recordings use five-minute chunks with one second of overlap; word midpoints assign overlap words to one chunk, and timestamps are shifted to the original video timeline. Speaker labels are scoped to each chunk because separate requests cannot establish a person's identity across chunks. If Economy receives a bad request or no word timings from Whisper, it retries that chunk with MAI and uses MAI for the remaining chunks. Speech without word timing after that retry fails instead of creating fabricated captions; a valid empty transcript can use visual-only planning in either mode. MAI does not supply the old provider's audio-event tags, so those remain empty.

Requests reject redirects, have a 90-second network timeout, and bound both audio and response sizes. The engine uses returned `usage.cost` when available, including zero; otherwise it estimates at $0.10 per input audio hour for MAI or $0.0108 for Whisper Turbo, the OpenRouter listed prices on 2026-09-24. Overlap audio counts toward provider usage. Automation transcription requests text only and bounds the combined transcript before metadata generation.

`bridge/test_openrouter_transcription.py` covers the request, word timing, speaker 0, chunk offsets, cost reporting, silence, malformed results and safe provider failures. Automation tests exercise the OpenRouter payload with local mock services. Live provider behavior still needs a controlled run with an OpenRouter account; automated tests do not spend provider credits.
